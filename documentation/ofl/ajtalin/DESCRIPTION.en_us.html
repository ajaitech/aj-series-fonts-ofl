AJ Talin is part of the original AJ Series 4-tier enterprise typeface superfamily designed by Aravind Jayamohan in India. Role: Level 3 · 3rd-Level Text & Accents — 0-deg Straight Connected Running Script (calt) + 11-deg Italic. Engineered with full Google Fonts Latin Core coverage, distinct per-family styling across 25+ native languages (Pan-European, Vietnamese, Arabic RTL, Devanagari Hindi/Marathi, Tamil, Telugu, Bengali, Japanese Kana) and 28 global currencies including Unicode 17.0 Saudi Riyal (U+20C1) and Unicode 18.0 UAE Dirham (U+20C3).
